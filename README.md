# Eclipse Kura™ Management UI

The web console of [Eclipse Kura™](https://github.com/eclipse-kura/kura): the administration
interface served by a gateway on `https://<gateway address>/`, from which the framework is
configured — services, network, firewall, cloud connections, wire graphs, drivers and assets,
certificates, identities, snapshots and deployment packages.

It is an add-on, not part of the framework: the repository builds a single OSGi bundle,
`org.eclipse.kura.web2`, and the Debian package that installs it into an existing Kura
installation. The user interface is written in [GWT](https://www.gwtproject.org/) and
cross-compiled to JavaScript; the server side talks to the framework through the Kura API and
registers its servlets and resources on the OSGi HTTP whiteboard.

## Requirements

* JDK 21
* Maven 3.9 or later

The GWT compiler accepts Java 17 at most, so the code under `client/` and `shared/`, which it
cross-compiles, cannot use anything newer than that.

## Build

```bash
mvn clean install
```

The reactor produces the bundle in `org.eclipse.kura.web2/target/` and the package in
`distrib/target/deb/`. Checkstyle runs during `process-sources` with the Eclipse Kura ruleset,
and the unit tests run with the bundle.

| Module | What it builds |
| --- | --- |
| `checkstyle-resources` | the suppressions this project adds to the Kura ruleset |
| `bom` | the bill of materials of the project |
| `org.eclipse.kura.web2` | the console bundle, GWT compilation included |
| `distrib` | the `.deb` package |

The manifest is generated by [bnd](https://bnd.bndtools.org/) from `org.eclipse.kura.web2/bnd.bnd`,
which also embeds the three GWT jars the bundle ships on its `Bundle-ClassPath`.

## Install on a gateway

The package requires Eclipse Kura 6 (`kura-core (>= 6.0.0~)`), which it installs the bundle into.

```bash
scp distrib/target/deb/kura-management-ui_*.deb root@<gateway address>:/tmp/
ssh root@<gateway address> 'apt-get install -y /tmp/kura-management-ui_*.deb && systemctl restart kura'
```

The console answers on `https://<gateway address>/`, which redirects to the login page.
